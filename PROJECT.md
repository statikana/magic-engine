# Project: mtg-engine

## Architecture

`mtg-engine` is a pure, deterministic, arena-based Magic: The Gathering rules engine in Rust (`edition = "2024"`, 7-crate workspace), bridged from the reference TypeScript engine (`COMPILER_VERSION = 46`) via IR v2 (`cards.bin`) and differential replay traces (`TsReplayTrace`).

### Crate Boundaries
- `crates/mtg-ir`: Pure data IR v2 schema (`IrV2Bundle`, `CardDatabase`, `CardDef`, `FaceDef`, `InternTables`, `ManaCost`, `ObjectFilter`, `EffectOp`, `StaticDef`, `TriggerDef`, `ReplacementDef`), pre-parsed bitmasks (`ColorMask`, `CardTypeMask`, `SupertypeMask`, `ZoneMask`, `FilterFlags`), `cards.bin` wire codec (`b"MTGC"` + `2u32` LE + compression flag `0|1` + `postcard` + optional `zstd`). Zero IO/regex/`GameState`, `--no-default-features` WASM-safe. All structs use `#[serde(deny_unknown_fields)]`, no `skip_serializing_if`, and externally tagged enums.
- `crates/mtg-engine`: Pure deterministic rules state machine organized by Comprehensive Rules domain (zero `waveN` filenames, zero IO, zero wall-clock time, zero async, zero Oracle-text reads or card-name rule dispatch). Arena-allocated `GameObject`s with generational `ObjectId { index, generation }`, private `GameState` fields with `DirtyMask`/`layer_rev` O(1) `OnceLock<LayerCache>` (`Send + Sync`), single `CR 400.7` `move_object_raw()`/`move_object()` funnel across all 7 zones (including `Stack`), `CR 613` + `CR 613.8` continuous-effect dependency resolution with signed unclamped `Option<PowerToughness>`, unified `CR 614–616` replacement pipeline with `PendingReplacementState`, sequential `CR 601.2` casting, `CR 506–511` combat, `CR 704` SBA fixpoint, `CR 603` APNAP triggers (+ `CR 605.1b/605.4a` triggered mana abilities), `CR 903` Commander rules, `MatchSession` façade, `Observation` + `determinize()`, `GameStateSnapshot`, and `TsReplayTrace` parity types.
- `crates/mtg-cli`: Native CLI binary providing `build-db`, `inspect-db [--verify-precons]`, and `diff-test`.
- `crates/mtg-ai`, `crates/mtg-compiler`, `crates/mtg-wasm`, `crates/mtg-py`: Downstream/adjacent workspace crates kept compiling cleanly (`fmt`, `clippy -D warnings`, `test`, `mtg-wasm --features wasm`).
- External TS Bridge (`/home/ryan/statikana/peckhamr.com/scripts/`): Two standalone Node v24 native-TS scripts ONLY (`export-ir-v2.ts`, `record-ts-replay.ts`), leaving all existing files in `peckhamr.com` untouched.
- Independent E2E Suite (`/home/ryan/statikana/mtg-engine/e2e/`): Standalone opaque-box integration test crate (`[workspace]` isolated) exercising `MatchSession` and `mtg-cli` using synthetic/renamed cards only.

## Interface Contracts

### 1. TS `export-ir-v2.ts` ↔ `crates/mtg-ir` (`IrV2Bundle` & `cards.bin`)
- `IrV2Bundle`: `snake_case` structs (`ir_version: 2`, `source_compiler_version: 46`, `tables`, `cards`, `decks`) with `#[serde(deny_unknown_fields)]`, zero `skip_serializing_if`, and externally tagged enums.
- Bitmasks (`ColorMask(u8)`, `CardTypeMask(u16)`, `SupertypeMask(u8)`, `ZoneMask(u8)`, `FilterFlags(u64)`): serialize/deserialize as raw unsigned integers in JSON (`serde_json`) and raw fixed-width integers in `postcard`. **`FilterFlags` is frozen at bits `0..=52`** (`<= Number.MAX_SAFE_INTEGER`); any newly discovered corpus filter booleans map to `ObjectPredicate`. TS computes `FilterFlags` bits `>= 31` via `BigInt`.
- `ManaCost::push_symbol`: handles `{C/P}` (`ManaPip::Phyrexian { color: ManaColor::C }`) before `("C", c)`, and `generic: u32` handles `{1000000}`.
- `ZoneChangeMod::opponent_discard_to_battlefield`: `Option<OpponentDiscardToBattlefield>` (`Plain | WithCounters { counter: CounterId, count: u16 }`), zero `Option<Option<...>>`.
- `cards.bin`: `b"MTGC"` (4 bytes) + `2u32` LE + compression byte (`0` raw, `1` zstd) + `postcard` payload.

### 2. TS `record-ts-replay.ts` ↔ `crates/mtg-engine/src/replay.rs` (`TsReplayTrace`)
- Matches `docs/07` §1.1 + canonical object locators:
  - `format_version: 1`, `compiler_version: 46`, `seed: u32`, `post_init_rng_state: u32`, `rules: { starting_life, commander, free_first_mulligan }`.
  - `seats: [{ seat, deck_id, commanders, library_order_initial, hand_initial }]`.
  - `steps: [{ step_index, actor_seat, action, object_locators: Map<InstanceId, ObjectLocator>, digest_after }]`, where `ObjectLocator` identifies every TS `instanceId` referenced in `action` or `battlefield` (e.g., `{ seat, zone, zone_index, oracle_id }` or `{ initial_card_ordinal, token_seq }`).
  - `TsStepDigest`: `turn_number`, `active_seat`, `priority_seat`, `phase`, `stack_depth`, `pending_prompt_kind`, `players: [{ seat, life, lost, poison, energy, mana_pool, zone_counts, hand_oracle_ids, battlefield }]`.
- `record-ts-replay.ts` temporarily stubs `Math.random` during `createInitialGameState` (and/or captures `postInitRngState`), runs with `isBot: false` during setup (driving explicit `mulligan_keep` / `mulligan_take` actions), and drives gameplay directly via exported `engine.ts`/`ai.ts` helpers passing explicit payloads to `applyGameAction`.
- Phase 1 traces exercise the vertical-slice card/mechanic subset implemented by M5 (`docs/KNOWN_TS_CR_DIVERGENCES.md` records any intentional CR improvements).

### 3. `mtg-engine` Internal CR Boundaries & Pinned State Contracts
- **Library-top convention:** `PlayerState.library` places the **top** of library at `library.last()` (`Vec::pop()` / `Vec::last()`). Immediately after TS-compat descending Fisher-Yates shuffle (where TS `engine.ts:496` puts top at index `0`), Rust reverses `library` so `library.last()` equals TS `library[0]`.
- **`GameState` privacy & `OnceLock<LayerCache>` (Option A, `Send + Sync`):**
  - All `GameState` fields are private to mutators; every mutation calls `mark_dirty(DirtyMask)` which increments `layer_rev`, ORs `dirty_since_eval`, and resets `layer_cache: OnceLock<LayerCache>` only when `(mask & cached.reads_mask) != DirtyMask::empty()` (O(1) selective skip!). `GameState::clone()` resets `layer_cache` to `OnceLock::new()` for sub-20µs clone speed.
  - `evaluate_board(&GameState) -> &LayerCache` computes/memoizes via `OnceLock::get_or_init`, preserving `&self` immutability and `Send + Sync` for `rayon` in `mtg-ai`. Under `#[cfg(feature = "verify-layer-cache")]`, every query cross-checks against fresh uncached recomputation.
- **Zone funnel (`CR 400.7`):** M2 exposes `move_object_raw(state, id, dest, lki_eval: Option<&EvaluatedObject>)`; M4 wraps it in `move_object()` with `CR 614–616` replacements and `CR 603` atomic events. All 7 zones including `Zone::Stack` enter/leave exclusively through this funnel.
- **Pinned `state.rs` sub-state contracts (to prevent M2–M5 collisions):**
  - `StackEntry`: `{ id: StackItemId, kind: StackEntryKind::{ Spell { object: ObjectId }, Activated { source: ObjectId, ability_idx: usize, lki: LkiSnapshot }, Triggered { source: ObjectId, ability_idx: usize, lki: LkiSnapshot } }, controller: PlayerId, choices: StackChoices, targets: Vec<TargetRef>, x_value: u32, paid_mana_colors: ColorMask }`.
  - `PendingReplacementState`: serializable struct stored on `GameState` holding the in-progress replaceable event + `applied: SmallVec<[ReplacementSourceId; 4]>` (`CR 614.5`) so `ChoiceRequest::ChooseReplacement` pauses survive `snapshot_bytes()`.
  - `CastingState`: serializable struct on `GameState` (for `DecisionState::CastingSequence`) holding `caster`, `object`, `face_idx`, `from_zone`, `step: CastStep`, `chosen_modes`, `x_value`, `optional_costs`, `targets`, `divisions`, `locked_cost`, `mana_paid`.
  - `CombatState`: serializable struct on `GameState` holding `attackers`, `blockers`, `damage_assignment_order`, `first_strike_dealt`, `combat_damage_dealt`, `attacked_this_combat`.
  - `ResolutionFrame`: serializable stack of paused effect frames on `GameState` holding `stack_item: StackItemId`, `steps_remaining`, `pc`, `bindings` (`bind_as` LKI), `pending_prompt_id`.
- **`EvaluatedObject.pt: Option<PowerToughness>`:** Signed unclamped `i32` through Layer 7d; clamping (`max(0)`) occurs strictly at action/damage sites.

### 4. `MatchSession` Public Façade & Snapshots (`crates/mtg-engine/src/session.rs`)
